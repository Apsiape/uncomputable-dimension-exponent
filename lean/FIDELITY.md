# Definition fidelity to the v4 paper

Theorem 1.2 of v4.0.0 (label thm:main, eq. (1.4)) is Lean-checked, conditional on the explicit hypothesis TarskiDecision (Basu-Pollack-Roy, Theorem 13.13).

Reference: *The uncomputable price of precision*, v4.0.0, October 2026, DOI [10.5281/zenodo.23753741](https://doi.org/10.5281/zenodo.23753741). This map uses the supplied read-only LaTeX source, not an assumption that the local PDF is current. PAPER-SOURCE-SHA256.json identifies the source files inspected. The blind fidelity audit downloaded the v4.0.0 Zenodo deposit and compared it byte-for-byte with the supplied source; DOI/source identity is established. The historical source hashes below refer to v4.0.0, before this release's additions.

The frozen statement bundle consists of Statement.lean and the four definition modules identified by STATEMENT-SHA256.json. FROZEN-STATEMENT.md displays all their statement-level definitions. The following rows cover every declaration in that display; imported Mathlib primitives retain their pinned Mathlib meanings. Construction details outside the statement bundle are not asserted to be textually identical to the paper.

| Lean declaration(s) | Paper location and meaning | Fidelity / convention |
|---|---|---|
| `Mat` | compiler/game sections, finite complex matrices | Square matrices indexed by Fin d; representation only. |
| `BCSGame` | compiler opening paragraph; intro `thm:main` | Finite contexts/variables, arbitrary Boolean predicates with a valid answer, rational positive incidence probabilities. The type is wider than the paper's chosen uniform incidence distribution. The actual compiler uses CompilerGame.uniform, so the constructed witness is uniform. Nonempty valid-answer predicates and full support on listed incidences are explicit restrictions; unsatisfiable contexts/zero-weight listed incidences are excluded. |
| `Strategy` | intro dimension definition; game `prop:game-transfer` | Arbitrary positive trace-one mixed bipartite density and arbitrary POVMs. Both spaces have dimension d; unequal spaces of dimension at most d can be padded equally as in the paper. Alice labels every variable, including those outside her context; locality makes these redundant outcome labels. Invalid labels remain as losing outcomes. This is an encoding enlargement, not a projective/pure-state restriction. |
| `winningProbability` | compiler context-variable consistency test | Weighted probability sum of traces of rho(A tensor B); Alice must satisfy the predicate and agree with Bob. Bool replaces signs by a two-element relabeling. |
| `loss` | loss throughout intro/prelim/game | Exactly one minus winning probability, with non-strict loss threshold. |
| `quantumValue` | intro `thm:main`, omega_q | Supremum over all positive finite common local dimensions and strategies. No commuting-operator/infinite-dimensional strategies are included. |
| `Feasible` | prelim `lem:computability` | Positive d and existence of a mixed POVM strategy of loss at most epsilon. Exact equality at the threshold is allowed, matching the paper. |
| `dimension` | intro D_G definition | Least positive feasible common local dimension; infinity if none. Padding convention matches. |
| `logDimension` | intro/game base-two log D_G | Uses ENat.toNat and Real.logb. At infinity the total Lean expression returns the library's zero convention rather than an extended logarithm. DimensionExponent explicitly rules out infinity for every positive precision, so that extra totalization is not used by the theorem. |
| `NoPerfectStrategy` | intro `thm:main` | Every positive finite-dimensional mixed POVM strategy has nonzero loss. Zero-dimensional objects are explicitly outside the quantifier. |
| `DimensionExponent` | intro `eq:main`; game proof interpolation | Finiteness for every positive real precision and the log-ratio limit as epsilon tends to zero from above. This is the logarithmic form of epsilon^(-beta+o(1)). The explicit all-positive-precision finiteness conjunct is stronger than a bare asymptotic formula, but follows from the value-one conclusion. No rational/dyadic-only limitation. |
| `dyadicSlope` | intro final sentence of `thm:main`; game proof | log_2 D_G(2^(-n))/n. Lean additionally defines n=0 by division-by-zero convention (zero); this finite initial term has no effect on eventual convergence/rates. |
| `haltingSet` | intro: fixed standard effective program enumeration | K is {e : Mathlib partial-recursive code e halts on input 0}, concretely `Nat.Partrec.Code.eval (Nat.Partrec.Code.ofNatCode e) 0`. The paper leaves the acceptable numbering unspecified; the exact real depends on that choice. Other acceptable numberings are not separately checked. |
| `haltingWeight` | intro `eq:main` | Exactly 4^(-(e+1)), starting at e=0. |
| `thetaK` | intro `eq:main`; source flag density | Sum of halting weights via tsum with zero on nonhalting indices. Matches the selected numbering. |
| `betaK` | intro `eq:main` | Exactly (3+thetaK)/4, with no rescaling or alternate target. |
| `rationalCode` | prelim finite-precision computation and rational approximation | Mathlib's surjective rational decoder, undefined codes mapped to zero. Coding choice, not a new mathematical premise. |
| `EffectiveCoding.ratPrimcodable`, the `Primcodable ℚ` instance | prelim finite-precision computation; standard rational coding | The rational Primcodable instance uses Mathlib's standard encoding: `toEncodable = Rat.instEncodable` by `rfl`. `E2/EffectiveCoding.lean` is frozen with the statement; its remaining declarations prove the effective coding operations. |
| `realOracle` | game proof: oracle for thetaK/betaK | Total characteristic oracle of the strict rational lower cut, encoded as a partial-function value. The paper leaves its real-oracle representation implicit. This has the intended real Turing degree for betaK. |
| `haltingOracle` | game proof: oracle for K | Total characteristic function with values 0/1, represented in Mathlib's partial oracle type. |
| `ExponentHasHaltingDegree` | intro `thm:main`; game proof | TuringEquivalent of the fixed betaK lower-cut oracle and halting oracle. Parameterless because this theorem fixes betaK. It is not an oracle for a varying game. |
| `ComputableReal` | prelim `lem:computability` | Total computable rational approximation with absolute error at most 2^(-(k+1)). Explicit representation convention. |
| `ComputableRealSequence` | same lemma's computable sequence/envelope | A single total algorithm jointly in term n and accuracy k; uniform computability, not an independent algorithm chosen for each n. |
| `CertifiedRate` | prelim `lem:computability`, eventual r(n) bound | Uniformly computable real-valued r tending to zero and eventually bounding absolute slope error. No monotonicity, effective onset threshold, or supplied modulus of r's convergence is required. At least as broad as a rational computable error envelope. Thus negating it covers that paper reading too. It does not merely negate one fixed exponential error rate. |
| `RealArithmetic.Factor`, `Poly` | prelim `lem:computability`, rational polynomial constraints | Finite lists of rational constants or natural-indexed variables, summed products. Wider syntactic redundancy, same commutative real polynomial semantics. |
| `factorEval`, `eval` | same lemma | Coercion of rationals to reals and finite products/sums. Empty product is one, empty sum zero. |
| `constant`, `var`, `add`, `neg`, `mul`, `sub`, `sum` | same lemma, forming polynomial constraints | Explicit syntax constructors; multiplication expands products of sums. These are finite syntax operations, not a real-number oracle. |
| `Atom`, `holds` | same lemma and BPR Theorem 13.13 | Boolean selects equality to zero or nonnegativity. |
| `Sentence`, `Truth` | same lemma's conjunction of feasibility constraints | Finite conjunction under existential real assignment. Empty conjunction is true. |
| `Literal`, `OrderedRingSentence`, `literalHolds`, `OrderedRingTruth` | BPR Theorem 13.13; prelim's quantifier elimination sentence | Finite existential DNF; negation supplies strict inequalities and disequalities. Empty disjunction is false. Natural-indexed valuations do not add infinitary strength: ordered_truth_finite proves finite-coordinate equivalence. This normalized syntax is narrower than all first-order formulas, exactly the existential fragment needed here. |
| `TarskiDecision` | BPR Theorem 13.13, printed p. 516 | ComputablePred of the preceding truth predicate. Explicit external theorem argument; no assumed feasibility solver, strategy existence, or efficiency premise. The paper states real quantifier elimination without supplying a verified implementation; this is the formal boundary. |
| `MainStatement` | intro `thm:main`, `eq:main`; game proof | Conjunction of the game, value, no-perfect, full exponent, degree, and no-rate claims. It is an existential result; no canonical literal game table is exposed by the statement. It does not include later classification or entanglement claims. |

Conventions and scope: BCS type allows nonuniform weights although the witness is uniform; nonempty/full-support predicates explicit; total-assignment outcome representation; equal padded local dimensions; totalized log at infinity/n=0; concrete halting enumeration and lower-cut real oracle; explicit all-positive-precision finiteness; broad eventual real-valued certified envelope; external existential-real decision premise. None of these is silently treated as the v4 classification theorem. The encoding and totalization conventions are separated from genuine scope restrictions above.

The paper's other imported inputs (the DM-precision theorem, Holevo's theorem, counter-machine universality, and Shoenfield's limit lemma) are not hypotheses or axioms of the Lean statement. TarskiDecision is a faithful, true rational-coefficient special case of Basu-Pollack-Roy, Theorem 13.13 (second edition, ISBN 978-3-540-33098-1, printed p. 516); its explicit use does not make the conditional theorem vacuous.
